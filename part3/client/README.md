# Part 3: Vector Databases and RAG (Retrieval-Augmented Generation)

## Getting Started Client

This is the client for Part 3.  You can start the client with the following:

1. Install dependencies
- In a terminal, navigate to the `part3/client` directory and run the following commands:
```
~/ai-for-devs/part3/client % npm install
```

2.  Launch the client
- Afterwards, run following command:
```
~/ai-for-devs/part3/client % npm run dev
```

3. Open your web browser and visit: http://localhost:5173
